# リハス地方の村

- ID: `rihasVillage`
- サイズ: 38 × 25マス、共通48pxタイル
- 正式データ: `maps.js`
- エディター作業記録: `rihasVillage.record.json`
- 本体のマップ描画処理による全景: `rihasVillage-preview.png`
- 通りをゲーム内サイズで切り出した表示確認用画像: `rihasVillage-street-preview.png`
- 人物と建物の縮尺確認用画像: `rihasVillage-scale-preview.png`（表示比較用の人物で、NPCの追加ではない）

## 物語での用途

参照: `../メモ/ストーリー.docx` の「リハス出身地方/C」「回収/A」、`../メモ/主要メンバーメモ.txt` のリハスの人物背景。

リハスが魔物から救い、後に住民から疎まれるようになった村。初回は討伐依頼と案内役の出発、再訪時は魔物から村人を守る場面に使う。固有の村名は未定なので、地方名で識別する。祖父母の家・火災・墓参りの場所は村外のため含めていない。

## 既存マップとの統一

クラク村（`startTown01`）とオトール村（`otoru_village`）を実際に描画して比較した。

- 地面は両村と同じ `grassBase`、土道は `villageTile04`。マップ外の地面は `test_grass`。
- 森は既存の `tree` を密集させ、集落の輪郭に沿って空けた。木の寸法は既存の96×96px。
- 建物の占有範囲は正面・横向きとも共通の3×2マス。横向き7棟は、配置済みの正面民家の本体の見える面積・基礎位置に揃えた村専用の縮尺を使用。元画像の縦横比を保ち、共通の建物定義は変更していない。
- 井戸・柵・花・街灯も既存タイルを既定寸法で使用。
- 草と道には共通タイルを使用。横向きの建物用に村専用の7定義を追加した。以前生成した苔色の家は未採用のため、参照がないことを確認して削除した。
- 既存10マップのデータと接続は変更していない。

## ゲーム本体の処理を用いた確認

ブラウザーのUI操作ではなく、現在の `world/tileMapSystem.js` と `world/townController.js` をそのまま読み込んで検証した。

- `switchTownMap` による村の読込と指定マスへの入場、読込後の暗転解除を確認。
- 入場位置から各施設まで、本体のWASD入力・移動更新処理で移動を確認（武器屋17歩、防具屋22歩、宿屋17歩、依頼所11歩、アイテム屋15歩）。
- 全施設の正面3マスずつ、計15マスで本体の `getTownInteraction` と `interactTown` を使用。武器・防具はそれぞれ正しい装備店、宿屋・アイテム屋・依頼所は対応する利用画面が開くことを確認。
- 本体の移動処理で、住宅と森へ進入できないことを確認。
- 全441通行可能マスが接続し、全施設と上記7か所の入口側へ到達可能。建物の重複や範囲外配置、存在しない画像への参照はない。
- 横向きの建物7か所へ本体のWASD入力・移動更新処理で移動し、中央通りの左右の民家の側壁へ進入できないことを確認。施設5か所の正面計15マスから対応する利用画面が開くことも再確認した。
- 本体の `drawTileMap` の描画指示を使って全景を書き出し、既存2村と目視比較。
- 作業記録JSONをエディターの読込処理へ戻した結果が正式マップと一致することを確認。

## 道幅の調整

- 南北の幹線はS列・T列の2マス幅で統一。北端から南端まで、途中で3〜5マスへ広がる箇所を解消した。
- 北・中央・南の横通りも2マス幅（9〜10行、14〜15行、20〜21行）。住宅・畑・井戸へ向かう枝道は1マス幅。東側路地の不規則な膨らみを除いた。
- 南の花壇は道から外し、AB22の草地へ移動。北端・南端の道幅に合わせて森の木を4マス調整した。
- 本体の移動処理で道のみを通って各入口へ到達できることを確認。施設5か所の正面15マスで利用画面を開くこと、全441通行可能マスの接続、保存後の正式データと作業記録の一致を確認した。
- 本体の描画処理による全景と通りの画像を更新し、幅・分岐・小物との重なりを目視確認した。ブラウザーでの手動プレイは実施していない。

## 地面画像の継ぎ目の修正

道の `villageTile04` と草地の `grassBase` の画像から暗い縦横の枠線を除去した。48pxの不透明PNGとして既存の参照先に反映し、使用画像は共通タイルの参照先に集約し、8×8枚の比較と編集条件を `img_tile/seamless_village/` に保存。上下・左右の端のRGB一致と、街の全景・通りで格子状の継ぎ目が消えることを確認済み。素材・編集条件は同フォルダーの `README.md` に記録している。

## 周辺地域と物語の接続

エディター／ゲームのマップデバッグに「リハス地方の村」として登録済み。通常進行からの接続、村外の討伐場所、案内NPC、初回・再訪のイベント演出は未設定。メモ上の未制作地域を飛ばす経路や、オトール村の北にある洞窟への道を置き換える接続は追加していない。
