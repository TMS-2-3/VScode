# 40×20のコンパクトな町

80×80版を残したまま作成した別マップ。IDは `rihasTown40`。32pxタイル・40×20マス（1280×640px）で、建物18棟・住人7人を配置した。

- `preview.html`: 全景・歩行確認。WASD／矢印キーで移動、Eで会話・入口確認。建物や門の前後関係も表示する。
- `editor.html`: 既存エディターで40×20版を選択した状態で開く。80×80版も引き続き選択できる。
- `town40-preview.png`: 住人を含む全景。
- `town40.record.json`: 作業記録。
- `town40-map.js` / `town40-tiles.js` / `town40.tiles.json`: 独立したマップ・タイル定義。
- `layout.json`: 建物・入口・配置物の座標。
- `verification-report.json`: 検証結果。

北に教会と各店舗、西に住宅・菜園・納屋・井戸、東に屋台と酒場・宿、中央に噴水広場、南に門を配置。主な道は2マス幅とし、各入口への細い道をつないだ。中央広場の南西には3×3マスの空間を残している。

建物の縦横比を保って小型版専用の表示寸法・占有範囲を設定した。80×80版の定義や画像は変更していない。建物・小物・人物などの素材は `../town80/assets/` を読み取り専用で共有し、40×20版専用の地面の境目だけを `assets/ground/` に保存している。元素材と生成条件は80×80版の `art-prompts.json` を参照。

## 確認

全414通行可能マスがつながり、全18棟の入口へ到達できる。既存の本体処理を32pxの検証用設定で実行し、施設5種類、住人7人の会話、南門・教会の当たり判定、エディター記録とJS書き出し、確認画面の移動・会話を検証した。画像も目視確認した。ブラウザー上の手動操作は未実施。

`preserved-town80.sha256.json` は作業開始前の80×80版の全300ファイルのハッシュ。検証時に内容が完全一致することを確認している。

今回の追加・変更は `map` 内のみ。共通処理とゲーム本体の48px設定は維持し、この町は独立データ・確認画面・エディターで扱う。通常進行への接続と屋内マップは未設定。

## 再生成

1. `node build-town.mjs`
2. `render-town.ps1 -MaterialsOnly`
3. `node verify-town.mjs`
4. `render-town.ps1`
