# 32px・80×80の町

中世ヨーロッパ風ファンタジーの町を、32pxタイル・80×80マス（2560×2560px）で制作した独立パッケージ。

## 開き方

- `preview.html`: 全景と歩行確認。WASD／矢印キーで移動、Eで会話・入口確認。地区選択とミニマップで移動できる。
- `editor.html`: 既存マップエディターで、この町を選択した状態で開く。
- `town80-preview.png`: 住人を含む全景。
- `town80-plaza.png` / `town80-church.png` / `town80-market.png` / `town80-residential.png` / `town80-gate.png`: 960×640pxの地区別表示。

ローカルファイルとして開ける。確認画面はこのフォルダーのデータと画像だけを使用する。

## 構成

- 建物21棟、建築の種類17種。同じ建築の使用は最大2棟。
- 中央は石畳の広場。噴水・ベンチ・街灯・花壇を置き、南西の5×5マスを演出用に空けた。
- 北に教会と前庭、東に武器屋・防具屋・道具屋・薬草店・パン屋と市場・水車小屋、西に庭と菜園のある住宅街、南に門・宿・納屋と農地を配置。
- 酒場は広場の南東。テラスのベンチと荷物を添えた。
- 住人11人は場所に応じた短い会話を持つ。物語の進行やクエストは追加していない。
- 主な移動路に加え、住宅を回る土道・店舗裏の路地・運河を渡る橋を用意。
- 樽・木箱・荷車・井戸・柵・花壇は用途のある場所に配置。建物の足元と木の下には影を付けた。

## データ

- `town80.record.json`: マップエディターの作業記録。32px・住人・入場位置などの情報を保持する。
- `town80-map.js`: 独立したマップ定義。IDは `rihasTown80`。
- `town80-tiles.js` / `town80.tiles.json`: 専用タイル定義。
- `town80-data.js`: 確認画面用のデータ。ビルド時に同じ記録から書き出す。
- `layout.json`: 建物・入口・橋・配置物の座標。
- `verification-report.json`: 最終検証の結果。
- `assets/source/`: 内蔵imagegenで作成した元アトラス。
- `assets/buildings/` / `assets/props/` / `assets/ground/` / `assets/people/`: 使用素材。地面32×32px、住人の歩行画像32×48px。色はRGB各5bit相当の段階に揃えた。

地面は16種類を基に、接続方向に応じた境目を作成。素材の縦横の端をなじませ、土道と石道の接続部には草の線が挟まらないよう調整した。人物素材は既存のNPC画像からゲーム用サイズへ整えている。

## 変更範囲とゲーム本体

今回の変更は `map` 内で完結している。`world`・`ui` など、他のフォルダーは変更していない。

既存ゲームの共通処理は48px固定のまま。この32pxの町は、独立データ・確認画面・マップエディターで扱う。既存ゲームの `maps.js` へは登録しておらず、通常進行への接続も未設定。エディターは32pxの記録保存・JS書き出しに対応し、48px用の本体データへ誤って反映する操作を防いでいる。

従来の38×25マスのリハス村と既存11マップの配置・接続は保持している。酒場・住宅などの屋内マップは未制作。

## 確認

`verify-town.mjs` は保存されたデータを新しい状態から読み直し、既存のマップ処理を32pxの検証用設定で実行する。ゲーム本体のファイルへの書込みは行わない。

- 全通行可能マスの接続と、住人を避けた全21棟への移動。
- 武器・防具・宿・道具屋・依頼所の正面計10マスで、対応する画面が開くこと。
- 全11人の住人への接近と会話開始。
- 南門・教会の壁の当たり判定、演出用5×5マスの確保。
- 画像の存在・地面32px・人物32×48px、エディター記録とJS書き出しの一致。
- 確認画面の初期化・移動・会話の処理。

全景と地区別画像を目視確認した。操作できるブラウザーが接続されていないため、ブラウザー上の手動操作確認は実施していない。

## 再生成

1. `prepare-assets.ps1` — 元アトラスから素材を切り出す。
2. `node build-town.mjs` — 配置・記録・タイル定義を書き出す。
3. `render-town.ps1 -MaterialsOnly` — 地面の境目を作成する。
4. `node verify-town.mjs` — 既存処理で検証し、描画指示を生成する。
5. `render-town.ps1` — 確認画像を書き出す。

画像は内蔵imagegenで作成した。使用プロンプトと加工条件は `art-prompts.json` に記録している。
